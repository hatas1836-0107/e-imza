OG Image Oluşturma Talimatları:

  1. site/og-image.html dosyasını tarayıcıda açın
  2. Tarayıcı penceresini tam 1200x630 boyutuna ayarlayın veya zoom kullanın
  3. Windows: Win + Shift + S ile ekran görüntüsü alın
  4. Veya: F12 > Device Toolbar > 1200x630 seçin > Screenshot
  5. Dosyayı site/assets/img/og-image.png olarak kaydedin

Alternatif Yöntem (Otomatik):

Aşağıdaki komutu çalıştırın:

# Windows PowerShell
Start-Process msedge.exe "http://localhost:8000/site/og-image.html"
# Manuel screenshot alın ve site/assets/img/og-image.png olarak kaydedin
